## プロジェクトのビルド

```shell
cd fpga_vu13p
make program
```

## 原理

* QSPI ポートの入力には必ずクロックがあるので、それをクロック源として UART ジェネレータを駆動します
* 各ピンがシリアル（UART）プロトコルで自分自身のピン情報を出力します。

## テスト

* テストポイントがある場合は、シリアルの RX 端子をテストポイントに当てればピン情報がわかります（受信ボーレート 115200）
* DDR のようにテストポイントがない場合は、チップを取り外し、シリアル受信器でパッドに触れる必要があります
