## NOTES

```
重要！ザイリンクスは、タンデムコンフィギュレーションを使用するユーザーに対し、bank 65 をデザインに使用しないよう推奨しています（特にタンデム PROM を使用する場合）。
これは、プログラミング用ビットストリームが 2 段階に分かれているため、複雑な操作を避けるためです。明確にしておくと、Memory Interface Generator (MIG) で生成した IP コアは
bank 65 の I/O を使用してはいけません。これにより IP が完全にステージ 2 に収まり、組み込み I/O と厳しいタイミング制約に起因する複雑な結果を避けることができます。
```
以上の理由から、tandem PCIe などを使用する場合、c3 の DDR4 は使えなくなります。このプロジェクトは DDR が使用可能かどうかをテストするためだけのものです。
