## NOTES

> **重要（Xilinx ドキュメントの注意事項の要約）:** タンデムコンフィギュレーションを使用する場合、bank 65 をユーザーデザインに使用しないことが推奨されています（特にタンデム PROM 使用時）。ビットストリームが 2 段階に分かれるため、手順が複雑になるのを避けるためです。特に MIG（Memory Interface Generator）で生成した IP は bank 65 の I/O を使用してはいけません。これにより IP 全体が Stage 2 に収まり、Stage 1 側の I/O や厳しいタイミング制約に起因する問題を避けられます。
以上の理由から、tandem PCIe などを使用する場合、c3 の DDR4 は使えなくなります。このプロジェクトは DDR が使用可能かどうかをテストするためだけのものです。
